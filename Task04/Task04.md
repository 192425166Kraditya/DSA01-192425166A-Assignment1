# Task 04 – Predict the Output

## 1. Objective
The objective of this task is to predict a C++ program's output by understanding variable initialization, assignment, arithmetic operations, and output statements.

## 2. Method
1. Read the given C++ program carefully.
2. Identify the initial values of all variables.
3. Trace each statement in execution order.
4. Record the expected output before running the program.
5. Compile and execute the program to verify the prediction.
6. Compare the predicted and actual outputs.

## 4. Analysis
C++ executes statements in sequence unless control-flow statements change the execution order. Variable values can change after assignment or arithmetic operations. Careful tracing helps predict the output correctly.

## 5. Complexity Analysis
The time complexity and auxiliary space complexity depend on the provided program. If it contains only a fixed number of statements and variables, both are generally O(1).

## 6. Conclusion
Predicting program output before execution improves understanding of C++ statement order and variable behavior. The prediction should be verified by compiling and running the original program.
